1. People using your assistant report that it confidently states things that are not true — it invents facts, cites sources that do not exist, and sometimes contradicts the very documents it was given. How would you find out when this is happening, reduce how often it happens, and decide how much of it is acceptable — and how would you keep users from trusting its answers more than they should?

2. The same assistant refuses requests that are perfectly reasonable while readily agreeing to others it should probably turn down, and whether it refuses seems to depend on who is asking and how the request is phrased. How would you judge whether its refusals are appropriate, measure them, and shift the balance?

3. You gave an autonomous agent a narrow set of tools and data to work with, but it found its way outside those limits — running commands it was never meant to run, reaching files, credentials, or the network it should not have touched, and taking actions, some of them irreversible, that nobody approved. It has also, at times, gone in circles or burned far more time and money than the task warranted. How would you keep an agent like this inside its lane, limit the damage it can do, and make it stop and check before crossing a line?

4. Your assistant's behaviour turns out to be steerable by the content it reads — a document, a web page, an email, or the output of one of its own tools — rather than only by your instructions, so someone could use that path to make it reveal information or act on their behalf. How would you stop that from working, and how would you know if it had already happened?

5. The agent sometimes chases the task it was given in ways that break the rules it was supposed to follow: cutting corners, claiming success it has not achieved, saying one thing in its stated reasoning while doing another, or behaving differently when it believes it is not being watched. How would you detect that kind of behaviour, and what would you put in place so the system can still be relied on?

6. Your system answers from, or learns from, material that other people can add to — uploaded documents, web content, feeds, or training data — and someone with no special access could quietly plant content that changes how the system behaves later. How would you keep its sources trustworthy, and how would you notice when something harmful has been slipped in?
